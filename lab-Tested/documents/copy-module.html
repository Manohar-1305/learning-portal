Copy Module

1. Create a source file on the controller

Create a file on the Ansible controller that will be copied to the managed host.

BASH — Command
echo "Welcome to Ansible learning" > message.txt

2. Copy a file using the Ansible copy module

Run the following ad hoc command on the Ansible controller:

BASH — Ad hoc command
ansible clients -m ansible.builtin.copy -a "src=message.txt dest=/tmp/message.txt"

The src parameter specifies the source file on the controller, and dest specifies the destination path on the managed host.

Expected output on the first successful copy:

OUTPUT — Expected result
ansible-client | CHANGED => {
    "changed": true,
    "dest": "/tmp/message.txt"
}

3. Verify the copied file

Run this command to read the file on the managed host:

BASH — Ad hoc command
ansible clients -m ansible.builtin.command -a "cat /tmp/message.txt"

Expected output:

OUTPUT — Expected result
Welcome to Ansible learning

4. Create a YAML playbook

Create a file named copy.yml on the Ansible controller.

BASH — Create the YAML file
cat > copy.yml <<'EOF'
---
- name: Copy a file to managed hosts
  hosts: clients
  become: true

  tasks:
    - name: Copy message file
      ansible.builtin.copy:
        src: message.txt
        dest: /tmp/message.txt
        owner: root
        group: root
        mode: '0644'
EOF

5. Run the YAML playbook

Execute the playbook:

BASH — Command
ansible-playbook copy.yml

Expected output summary:

OUTPUT — Expected result
PLAY RECAP
ansible-client : ok=2 changed=1 unreachable=0 failed=0

6. Verify the file permissions

Run the following command to check the file's permissions and ownership:

BASH — Ad hoc command
ansible clients -b -m ansible.builtin.command -a "stat -c '%a %U %G %n' /tmp/message.txt"

Expected output:

OUTPUT — Expected result
644 root root /tmp/message.txt

Important

The ansible.builtin.copy module copies files from the controller to managed hosts by default. It is idempotent, so it does not report a change when the destination already matches the desired content and attributes.
