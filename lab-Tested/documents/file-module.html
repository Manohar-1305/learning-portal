File Module

1. Create a directory using an ad hoc command

Run the following command on the Ansible controller to create a directory on the managed host:

BASH — Ad hoc command
ansible clients -m ansible.builtin.file -a "path=/tmp/ansible-demo state=directory"

The path parameter specifies the directory path, and state=directory ensures that the directory exists.

2. Verify the directory

Execute the following command to verify that the directory exists on the managed host:

BASH — Ad hoc command
ansible clients -m ansible.builtin.command -a "ls -ld /tmp/ansible-demo"

Expected output:

OUTPUT — Expected result
drwxr-xr-x ... /tmp/ansible-demo

3. Create an empty file

Use the file module to create an empty file on the managed host:

BASH — Ad hoc command
ansible clients -m ansible.builtin.file -a "path=/tmp/ansible-demo/test.txt state=touch"

Verify the file:

BASH — Ad hoc command
ansible clients -m ansible.builtin.command -a "ls -l /tmp/ansible-demo/test.txt"

4. Set file permissions

Set the file permissions to 0644:

BASH — Ad hoc command
ansible clients -b -m ansible.builtin.file -a "path=/tmp/ansible-demo/test.txt mode=0644"

Verify the permissions:

BASH — Ad hoc command
ansible clients -b -m ansible.builtin.command -a "stat -c '%a %n' /tmp/ansible-demo/test.txt"

Expected output:

OUTPUT — Expected result
644 /tmp/ansible-demo/test.txt

5. Set directory permissions

Set the directory permissions to 0755:

BASH — Ad hoc command
ansible clients -b -m ansible.builtin.file -a "path=/tmp/ansible-demo state=directory mode=0755"

Verify the directory permissions:

BASH — Ad hoc command
ansible clients -b -m ansible.builtin.command -a "stat -c '%a %n' /tmp/ansible-demo"

6. Change file ownership

Set the file owner and group to root:

BASH — Ad hoc command
ansible clients -b -m ansible.builtin.file -a "path=/tmp/ansible-demo/test.txt owner=root group=root"

Verify ownership:

BASH — Ad hoc command
ansible clients -b -m ansible.builtin.command -a "stat -c '%U %G %n' /tmp/ansible-demo/test.txt"

Expected output:

OUTPUT — Expected result
root root /tmp/ansible-demo/test.txt

7. Create a symbolic link

Create a symbolic link pointing to the test file:

BASH — Ad hoc command
ansible clients -m ansible.builtin.file -a "src=/tmp/ansible-demo/test.txt path=/tmp/ansible-demo/test-link.txt state=link"

Verify the symbolic link:

BASH — Ad hoc command
ansible clients -m ansible.builtin.command -a "ls -l /tmp/ansible-demo/test-link.txt"

8. Remove a file

Delete the symbolic link created in the previous step:

BASH — Ad hoc command
ansible clients -m ansible.builtin.file -a "path=/tmp/ansible-demo/test-link.txt state=absent"

Verify that the link no longer exists:

BASH — Ad hoc command
ansible clients -m ansible.builtin.command -a "ls -l /tmp/ansible-demo"

9. Create a YAML playbook

Create a file named file_module.yml on the Ansible controller.

BASH — Create the YAML file
cat > file_module.yml <<'EOF'
---
- name: Manage files and directories
  hosts: clients
  become: true

  tasks:
    - name: Create the learning directory
      ansible.builtin.file:
        path: /tmp/ansible-demo
        state: directory
        owner: root
        group: root
        mode: '0755'

    - name: Create an empty file
      ansible.builtin.file:
        path: /tmp/ansible-demo/test.txt
        state: touch
        owner: root
        group: root
        mode: '0644'

    - name: Create a symbolic link
      ansible.builtin.file:
        src: /tmp/ansible-demo/test.txt
        path: /tmp/ansible-demo/test-link.txt
        state: link
EOF

10. Validate the YAML playbook

Check the syntax before execution:

BASH — Command
ansible-playbook --syntax-check file_module.yml

Expected output:

OUTPUT — Expected result
playbook: file_module.yml

11. Execute the YAML playbook

Run the playbook on the managed hosts:

BASH — Command
ansible-playbook file_module.yml

Expected result summary:

OUTPUT — Example
PLAY RECAP
ansible-client : ok=4 changed=3 unreachable=0 failed=0

12. Remove a directory using a YAML playbook

Create a separate playbook named remove_directory.yml.

BASH — Create the YAML file
cat > remove_directory.yml <<'EOF'
---
- name: Remove the Ansible learning directory
  hosts: clients
  become: true

  tasks:
    - name: Remove the learning directory and its contents
      ansible.builtin.file:
        path: /tmp/ansible-demo
        state: absent
EOF

Run this playbook only when you intend to delete the directory and all its contents:

BASH — Command
ansible-playbook --syntax-check remove_directory.yml
ansible-playbook remove_directory.yml

Important

The ansible.builtin.file module manages file and directory state, permissions, ownership, and symbolic links. Use state: absent carefully because it removes the specified file or directory and its contents.
