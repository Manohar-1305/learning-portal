Ping Module

Verify Ansible connectivity between the controller and the managed host using commands executed directly in the terminal.

1. Check the inventory

Run the following command:

ansible-inventory --list

The inventory should contain the clients group and the ansible-client host.

2. Run the Ansible ping module

Execute:

ansible clients -m ansible.builtin.ping

Expected result:

ansible-client | SUCCESS => {
    "changed": false,
    "ping": "pong"
}

3. Verify SSH connectivity

Run:

ssh root@ansible-client hostname

Expected output:

ansible-client

4. Run a command on the managed host

Execute:

ansible clients -m ansible.builtin.command -a 'hostname'

Expected output:

ansible-client

Important

The Ansible ping module is not an ICMP network ping. It verifies that Ansible can connect to the managed host and execute the module using Python.
